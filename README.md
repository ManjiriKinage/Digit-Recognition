## 🔗 Live Application Demo
👉 **[Click Here to Test the Live Application](https://digit-recognition-1-2hor.onrender.com/)**

An end-to-end Machine Learning web application that predicts handwritten digits (0–9) in real-time from an interactive HTML5 drawing canvas or uploaded images. Built with a custom Deep Convolutional Neural Network (CNN) trained on the MNIST dataset, OpenCV preprocessing for Center-of-Mass alignment, and deployed via a secure, containerized Docker environment.

---

## 🌟 Key Features

- 🎨 **Interactive Drawing Canvas**: Smooth HTML5 canvas engine with responsive stroke controls, eraser mode, undo/clear, and instant vector digit presets.
- 🧠 **High-Accuracy CNN**: Deep Convolutional Neural Network with Batch Normalization and Dropout regularization achieving **~99.2% test accuracy**.
- 🔬 **Robust Computer Vision Pipeline**: Custom OpenCV image processing matching MNIST's exact standard:
  - Dynamic inverted thresholding
  - Bounding-box detection & aspect-ratio preserving 20×20 scaling
  - 28×28 zero-padding and **Center-of-Mass centroid alignment**
- 📊 **Real-Time Probability Distribution**: Animated Softmax confidence bars across all 10 digit classes (0–9).
- 👁️ **Neural Input Preview**: Visualizes the normalized 28×28 tensor generated by the preprocessing pipeline before feeding into the CNN.
- 📁 **Multi-format Image Uploads**: Drag-and-drop support for PNG, JPG, and WEBP image files.
- 🐳 **Production Docker Containerization**: Lightweight, non-root user image optimized for low-memory cloud execution with Gunicorn WSGI.

## 📊 Model Architecture & Performance

The model is trained on the **MNIST dataset** (60,000 training images, 10,000 test images) using Adam optimizer and Sparse Categorical Crossentropy.

### Layer Structure:
1. **Input Layer**: `(28, 28, 1)` Grayscale image tensor
2. **Conv Block 1**: 32 Filters (3×3), ReLU, Batch Normalization, MaxPooling (2×2), Dropout (0.25)
3. **Conv Block 2**: 64 Filters (3×3), ReLU, Batch Normalization, MaxPooling (2×2), Dropout (0.25)
4. **Conv Block 3**: 128 Filters (3×3), ReLU, Batch Normalization, MaxPooling (2×2), Dropout (0.25)
5. **Fully Connected Block**: Flatten, Dense (128 units, ReLU), Dropout (0.4)
6. **Output Layer**: Dense (10 units, Softmax Activation)

| Metric | Result |
| :--- | :--- |
| **Training Accuracy** | 99.64% |
| **Validation / Test Accuracy** | **99.20%** |
| **Test Loss** | 0.024 |
| **Inference Latency** | ~15ms |

## 🚀 Local Development Setup

### 1. Clone Repository & Install Dependencies
```bash
git clone https://github.com/ManjiriKinage/Digit-Recognition.git
cd Digit-Recognition

# Create virtual environment
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Install requirements
pip install -r requirements.txt
```

### 2. (Optional) Re-train the Model
To re-train the CNN from scratch on MNIST and generate metric plots:
```bash
python train.py
```

### 3. Run the Development Server
```bash
python app.py
```
Visit `http://127.0.0.1:5000` in your web browser.

## 🐳 Docker Deployment

### Run Container Locally:
```bash
# 1. Build the Docker image
docker build -t digit-recognition:latest .

# 2. Run container on port 7860
docker run -d -p 7860:7860 --name digit-app digit-recognition:latest
```
Access the application at `http://localhost:7860`.
